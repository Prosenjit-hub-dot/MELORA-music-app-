# MELORA Music App

A polished front-end prototype for the MELORA music brand.

## Included
- Responsive dark premium UI
- Home, Discover, Library, Playlists, Liked Songs, Downloads
- Search
- Music player controls
- Lyrics modal
- Mood discovery
- MELORA AI-style playlist generator
- Like/favorite persistence with localStorage
- Mobile navigation
- Ambient mode
- Sample MELORA original tracks

## Run
Open `index.html` in any modern browser.

This is a front-end prototype. Real audio streaming, authentication, cloud playlists, payments, artist uploads, and production AI would require a backend and/or music service APIs.
